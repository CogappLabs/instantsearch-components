Each component is a React InstantSearch widget: it reads and refines search
state through the `react-instantsearch` hooks, so it works with any backend
InstantSearch talks to, whether Algolia or Elasticsearch through Searchkit.

| Component | |
| --- | --- |
| [DateHistogram](components/date-histogram/) | A year range picked under a histogram of the records' years, or typed. |
